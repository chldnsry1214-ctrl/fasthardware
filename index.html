02

speedup() 호출 — 끝

프로그램 시작 시 단 한 번 호출하면, GPU 우선순위·스레드·cuDNN·OpenVINO 캐시가 모두 켜집니다.

python 
import fasthardware

# 기본 최적화
fasthardware.speedup()

# 멀티프로세싱 환경에서는 ULTIMATE 모드

03

카메라 스트림 레이턴시 제거

기본 cv2.VideoCapture는 버퍼 지연이 있습니다. FastVideoStream은 백그라운드 스레드로 항상 최신 프레임만 유지합니다.

python 
from fasthardware import FastVideoStream
import cv2

stream = FastVideoStream(src=0).start()

while True:
    frame = stream.read()         # 항상 최신 프레임
    cv2.imshow("Live", frame)
    if cv2.waitKey(1) == 27:
        break

stream.stop()
cv2.destroyAllWindows()

// API 레퍼런스

전체 API

fasthardware의 모든 공개 함수와 클래스입니다.

speedup(mode="DEFAULT") function

시스템 전체 하드웨어 가속을 활성화합니다. 프로그램 시작 시 단 한 번 호출하세요. CUDA → OpenVINO → OpenCV 순으로 감지하여 최적화합니다.

파라미터타입설명
mode str "DEFAULT" 또는 "ULTIMATE". ULTIMATE는 자식 프로세스에도 우선순위 및 CPU 코어 바인딩을 적용합니다.
get_core() → ov.Core function

speedup() 호출로 생성된 OpenVINO Core 싱글톤을 반환합니다. speedup() 전에 호출하면 RuntimeError가 발생합니다. 모델을 컴파일할 때 이 Core를 재사용하면 초기화 오버헤드가 없습니다.

manual_sweep() function

GC를 수동으로 실행하고 OS에 미사용 메모리를 즉시 반환합니다. speedup()은 GC 자동 수집을 비활성화하므로, 메모리를 해제하고 싶을 때 이 함수를 직접 호출하세요. Windows에서는 Working Set 크기를 트리밍하고, Linux에서는 malloc_trim을 호출합니다.

FastVideoStream(src=0) class

백그라운드 스레드에서 카메라를 상시 읽어 최신 프레임만 유지하는 고성능 비디오 스트림입니다. 기본 cv2.VideoCapture의 버퍼 지연을 제거합니다. Windows에서 CAP_DSHOW 백엔드를 사용하며, 해상도는 640×480, 버퍼 크기 1로 고정됩니다.

메서드설명
.start()백그라운드 스레드를 시작하고 self를 반환합니다. 체이닝 가능: FastVideoStream(0).start()
.read()가장 최근 프레임(numpy ndarray)을 반환합니다.
.stop()스레드를 종료하고 카메라 리소스를 해제합니다.

실전 예제

멀티프로세싱, 메모리 관리, OpenVINO 추론을 함께 쓰는 패턴입니다.

python — 딥러닝 추론 파이프라인 
import fasthardware
from fasthardware import FastVideoStream
import numpy as np

# 1. 하드웨어 가속 최적화
fasthardware.speedup()

# 2. OpenVINO Core 및 모델 로드
core  = fasthardware.get_core()
model = core.compile_model("yolov8n.xml", "AUTO")
infer = model.create_infer_request()

# 3. 카메라 스트림 시작
stream = FastVideoStream(src=0).start()

frame_count = 0
while True:
    frame = stream.read()

    # 전처리 → 추론
    blob = np.expand_dims(frame, 0)
    infer.infer({0: blob})

    frame_count += 1
    if frame_count % 500 == 0:
        fasthardware.manual_sweep()  # 주기적 메모리 정리
python — 멀티프로세싱 (ULTIMATE 모드) 
import fasthardware
import multiprocessing as mp

def worker(idx):
    print(f"Worker {idx} running")

if __name__ == "__main__":
    # 자식 프로세스까지 코어 바인딩 + 우선순위 상향
    fasthardware.speedup("ULTIMATE")

    pool = mp.Pool(processes=4)
    pool.map(worker, range(4))
    pool.close()
